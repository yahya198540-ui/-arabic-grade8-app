# معركة الحروف المفقودة — الصف الثامن (اللغة العربية)

لعبة قتال ومغامرات ثلاثية الأبعاد (Three.js) للتقويم الختامي لدرس «الحروف التي تُنطَق ولا تُكتَب».
إعداد: أ. يحيى الجابري.

## التشغيل

الملف الجاهز: **`public/battle.html`** (نسخة مطابقة في `battle/dist/index.html`) — ملف HTML واحد
يعمل بالنقر المزدوج دون خادم ودون إنترنت (الخطوط من خطوط النظام، والصوت والموسيقى والخامات تُولَّد برمجيًّا).

لإعادة البناء بعد أي تعديل:

```bash
cd battle
npm ci
npm run build      # يكتب dist/index.html و ../public/battle.html
```

## تعديل الأسئلة

كل الأسئلة والخيارات والإجابات الصحيحة والتغذية الراجعة ونقاط الدرجات في ملف واحد:
`src/questions.js` (`correct` = 0 للخيار أ، 1 ب، 2 ج، 3 د). الأسئلة الستة مطابقة حرفيًّا لنص الأمر.

## سير الحصة (≈ ٦ دقائق)

* ٦ مواجهات؛ يظهر الخصم، ثم تتوقف المواجهة وتظهر نافذة السؤال **دون عدّ تنازلي**.
* الإجابة الصحيحة من المحاولة الأولى = ١٠ نقاط، وبعد خطأ = ٥ نقاط (الحد الأعلى ٦٠).
* الخطأ: وميض أحمر خفيف + «حاول مرة أخرى» + انخفاض بسيط في الطاقة، وتبقى المواجهة مفتوحة (لا خسارة نهائية).
* الصحيح: أخضر + كرة طاقة + هزيمة كرتونية للروبوت + التغذية الراجعة + زر «المواجهة التالية».
* تظهر في النافذة عبارة «دور الطالب رقم N» لتسهيل مشاركة طالب مختلف في كل مواجهة.

## التحكم

* النقر/اللمس لاختيار الإجابة (والزر الكبير للمواجهة التالية؛ ويعمل Enter أيضًا).
* الحركة تلقائية بين المواجهات؛ للتوجيه: ← → أو A/D، وللتسريع/التبطئة ↑ ↓ أو W/S، أو السحب أفقيًّا بالإصبع.
* أزرار الأعلى: الصوت، الموسيقى، ملء الشاشة، جودة الرسومات (عالية/منخفضة، ويُخفَّض تلقائيًّا عند ضعف الأداء)، إعادة البدء (بتأكيد).

## الاختبار الآلي (Playwright + Chromium)

```bash
node test/play.cjs     # لعبة كاملة من الشاشة الافتتاحية إلى شاشة الانتصار + لقطات
node test/steer.cjs    # التوجيه اليدوي لا يمنع الوصول لأي مواجهة
node test/route.cjs    # مسارات اللاعب لا تصطدم بالحواجز
```

## البنية

| الملف | الدور |
|---|---|
| `src/questions.js` | الأسئلة والإعدادات |
| `src/game.js` | حالة اللعبة، المواجهات، الكاميرا، الواجهة |
| `src/world.js` | الساحة والقلعة العُمانية والعلم والجبال والنخيل والحواجز والكأس |
| `src/chars.js` | الطالب العُماني والروبوتات الستة وحركاتها |
| `src/particles.js`, `src/textures.js`, `src/audio.js` | المؤثرات، الخامات، الصوت |
| `template.html` | واجهة HTML/CSS (RTL، مقاس 16:9 متجاوب) |

## ملاحظة عن الصور المرجعية

المشهد كله مبني برمجيًّا بأسلوب كرتوني ثلاثي الأبعاد مستوحى من الصورتين المرجعيتين (التكوين، الألوان، شكل النافذة والأزرار
وشريط الطاقة والنقاط)، ولم تُستخدم الصور كخلفيات؛ وكل النصوص العربية تُكتب برمجيًّا.
