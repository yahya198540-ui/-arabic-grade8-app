# تطبيق تحضير دروس اللغة العربية - الصف الثامن

تطبيق ويب متجاوب (PWA) متخصص لتحضير دروس اللغة العربية للصف الثامن وفقاً لمنصة نور.

## ✨ الميزات

- **رفع الملفات المرجعية**: رفع دليل المعلم وكتاب الطالب (PDF)
- **نموذج تحضير شامل**: يحتوي على 9 حقول محددة حسب منصة نور
- **تخزين محلي**: جميع البيانات تُحفظ محلياً بدون الحاجة لسيرفر
- **واجهة عربية كاملة**: تصميم بسيط وسهل الاستخدام مع دعم RTL
- **أرشيف مع بحث**: تنظيم التحضيرات حسب الوحدة والتاريخ
- **تصدير PDF**: تصدير التحضير كملف جاهز للطباعة
- **تطبيق جوال**: يمكن تثبيته على الشاشة الرئيسية كـ PWA

## 🔧 البدء السريع

### التثبيت

```bash
npm install
```

### التطوير

```bash
npm run dev
```

سيفتح التطبيق على `http://localhost:5173`

### البناء للإنتاج


## 🚀 مغامرة العطف في الفضاء (ثلاثية الأبعاد)

لعبة تعليمية لدرس العطف (اللغة العربية – الصف الثامن) بمحرك Three.js (WebGL)، مصدرها في `adventure/` وناتجها ملف HTML واحد يعمل دون إنترنت.

- **الرابط:** `public/adventure.html` (يُفتح من `/adventure.html` أو من زر «مغامرة العطف»). أرسله للطلاب كرابط، أو ارفعه على أي استضافة ثابتة.
- **SCORM 1.2:** `public/adventure-scorm12.zip` — ارفعه إلى Moodle/Blackboard/Canvas وغيرها. يرسل الدرجة (من 10) وحالة النجاح (حدّ النجاح 6) ويحفظ التقدم (suspend_data).
- **الأسئلة:** 10 أسئلة معتمدة في `adventure/src/data.js` (3 خيارات لكل سؤال) موزعة على 3 مراحل: الانطلاق (1–3)، حزام الكويكبات (4–7)، إنقاذ المحطة (8–10).
- **العالم:** لا بوابات؛ عشرة كواكب حقيقية (`adventure/src/planets.js` تولّد تضاريسها على بطاقة الرسوم)، والسؤال يظهر عند المرور قرب كل كوكب، والإجابة الصحيحة تُحيي الكوكب بموجة ضوء. مواقع الكواكب والعقبات في `adventure/src/level.js` حسب المسافة، وبين كوكبين 20–28 ثانية لعب فعلي.
- **التحكم:** الفأرة، أو السحب باللمس، أو الأسهم / WASD.

### إعادة البناء

```bash
cd adventure && npm install && npm run build
```

يولّد `adventure/dist/` ويحدّث `public/adventure.html` و`public/adventure-scorm12.zip`. أضف `?q=low` للرابط لتشغيل جودة منخفضة على الأجهزة الضعيفة.
