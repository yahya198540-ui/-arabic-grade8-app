# تطبيق تحضير دروس اللغة العربية - الصف الثامن

تطبيق ويب متجاوب (PWA) متخصص لتحضير دروس اللغة العربية للصف الثامن وفقاً لمنصة نور.

## ✨ الميزات

- **رفع الملفات المرجعية**: رفع دليل المعلم وكتاب الطالب (PDF)
- **نموذج تحضير شامل**: يحتوي على 9 حقول محددة حسب منصة نور
- **تخزين محلي**: جميع البيانات تُحفظ محلياً بدون الحاجة لسيرفر
- **واجهة عربية كاملة**: تصميم بسيط وسهل الاستخدام مع دعم RTL
- **أرشيف مع بحث**: تنظيم التحضيرات حسب الوحدة والتاريخ
- **تصدير PDF**: تصدير التحضير كملف جاهز للطباعة
- **تطبيق جوال**: يمكن تثبيته على الشاشة الرئيسية كـ PWA

## 🔧 البدء السريع

### التثبيت

```bash
npm install
```

### التطوير

```bash
npm run dev
```

سيفتح التطبيق على `http://localhost:5173`

### البناء للإنتاج

```bash
npm run build
```

1. **عنوان الدرس والوحدة**
2. **الصف والشعبة والتاريخ**

4. **الوسائل والأدوات التعليمية**
5. **التمهيد (التهيئة للدرس)**

8. **التقويم (أثناء الحصة)**
9. **الواجب المنزلي / التقويم الختامي**

## 📁 هيكل المشروع

```
src/
├── components/
│   ├── Navigation.jsx           # شريط التنقل
│   ├── FileUploadSection.jsx    # رفع الملفات المرجعية
│   ├── LessonForm.jsx           # نموذج التحضير
│   ├── LessonArchive.jsx        # أرشيف التحضيرات
│   └── LessonDetails.jsx        # عرض تفاصيل التحضير
├── App.jsx                       # المكون الرئيسي
├── main.jsx                      # نقطة الدخول
├── db.js                         # قاعدة البيانات المحلية (Dexie)
├── constants.js                  # الثوابت والإعدادات
├── utils.js                      # دوال مساعدة
└── index.css                     # التنسيقات
```
